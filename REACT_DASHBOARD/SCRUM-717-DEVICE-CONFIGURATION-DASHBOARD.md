# SCRUM-717 Device Configuration Dashboard

The existing Device Inventory now opens a responsive Configuration dialog. It presents current settings, validation, save feedback, platform templates, immutable version history, actor/timestamp/changed fields, and confirmed restore. ADMIN can create/update templates; ADMIN and OPERATOR can save, apply, and restore on active devices. Inactive devices remain readable and hide mutation controls.

Loading, empty history/templates, backend errors, client validation, success, and centrally-stored-only messaging are explicit. The workflow does not claim that settings have reached a physical device.
